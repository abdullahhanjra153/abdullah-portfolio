## 🎨 Design System & Philosophy

- **Typography:** `Manrope` (headings and body) & `DM Mono` (data metrics, tags, badges).
- **Color Palette:** Warm editorial paper (`#f6f5f1`), deep slate ink (`#171916`), muted olive border (`#dcdcd4`), and vibrant electric lime accent (`#c9f269`).
- **Aesthetic:** Editorial minimalism with tactile noise grain texture, subtle orbit geometries, and fluid responsive grid.
- **Zero Build Step:** 100% pure semantic HTML5, modern CSS variables, and lightweight vanilla JavaScript.

## 🚀 Quick Start

Run the zero-dependency local development server:

```bash
# Clone the repository
git clone https://github.com/abdullahhanjraa/abdullah-portfolio.git
cd abdullah-portfolio

# Start the dev server with live reload
npm start
```

Or open `index.html` directly in any web browser.
